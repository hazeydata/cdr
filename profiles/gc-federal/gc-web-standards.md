# Government of Canada Web Standards

> **Sources:** Canada.ca Design System, WET/GCWeb, TBS Standards, Official Languages Act, FIP
> **CDR Context:** All tools built for GC federal departments must follow these standards

---

## 1. Canada.ca Design System

**Source:** [design.canada.ca](https://design.canada.ca/) | [Canada.ca Content and IA Specification](https://www.canada.ca/en/treasury-board-secretariat/services/government-communications/canada-content-information-architecture-specification.html)

### Mandatory Elements

#### Header (Required)
- [ ] Government of Canada signature (bilingual FIP: Flag + "Government of Canada / Gouvernement du Canada")
- [ ] Language toggle (English ↔ French) — top-right position
- [ ] Search bar (for Canada.ca sites; may be omitted for internal tools with justification)

#### Footer (Required)
- [ ] Government of Canada wordmark
- [ ] Standard footer links (Contact information, Departments and agencies, etc.)
- [ ] "Report a problem" link
- [ ] Date modified indicator

#### Page Elements
- [ ] Breadcrumb navigation
- [ ] Page title as `<h1>`
- [ ] "Date modified" at bottom of content

### When to Use Canada.ca Theme
- **Public-facing applications:** MUST use Canada.ca/GCWeb theme
- **Internal tools for GC employees:** SHOULD use GCWeb (recommended but may be relaxed)
- **All applications:** MUST comply with accessibility and bilingual requirements regardless of theme

## 2. Web Experience Toolkit (WET) / GCWeb

**Source:** [WET GitHub](https://github.com/wet-boew/wet-boew) | [GCWeb Theme](https://wet-boew.github.io/GCWeb/index-en.html)

### Technical Details
- **Base:** Bootstrap 3.3.7 (with GC modifications)
- **JavaScript:** jQuery 2.2.4
- **Accessibility:** WCAG 2.0 AA (aim for 2.1 AA)
- **Responsive:** Mobile-first
- **Languages:** Built-in bilingual support
- **Licence:** MIT

### Integration

```html
<!-- In HTML head -->
<link rel="stylesheet" href="GCWeb/css/theme.min.css">

<!-- Before closing body -->
<script src="wet-boew/js/wet-boew.min.js"></script>
<script src="GCWeb/js/theme.min.js"></script>
```

### GC Design System (For New Projects)
**Source:** [design-system.alpha.canada.ca](https://design-system.alpha.canada.ca)

The new GC Design System is the future replacement for WET/GCWeb:
- Modern web components (framework-agnostic)
- Design tokens for consistent styling
- Built for WCAG 2.1 AA from the ground up
- Works with React, Vue, plain HTML

**Recommendation:** Evaluate GC Design System for new projects. Use WET/GCWeb for stability today.

## 3. Official Languages Act — Bilingual Requirements

**Source:** [Official Languages Act](https://laws-lois.justice.gc.ca/eng/acts/o-3.01/)

### Must Be Bilingual
- [ ] All user interface text (menus, buttons, labels, messages)
- [ ] All error messages and validation messages
- [ ] All help text and tooltips
- [ ] All email/notification content generated by the application
- [ ] All PDF reports or documents generated
- [ ] All multimedia content (captions, transcripts)
- [ ] README and end-user documentation

### Can Be English-Only
- Source code (variable names, comments)
- Developer-facing documentation
- Commit messages
- Technical API documentation (bilingual recommended)

### Implementation Requirements
- [ ] Language toggle prominently placed (top-right of header per Canada.ca design)
- [ ] User language preference remembered (cookie or user profile)
- [ ] Both language versions launched simultaneously — no "English first, French later"
- [ ] French version is equal quality and functionality
- [ ] URLs reflect language: `/en/page` and `/fr/page`
- [ ] `<html lang="en">` or `<html lang="fr">` set correctly per page
- [ ] Mixed-language content marked with `lang` attribute on specific elements
- [ ] Date formats respect locale: "March 15, 2026" / "15 mars 2026"
- [ ] Number formats respect locale where applicable

### Implementation Pattern (Python/Flask)
```python
from flask_babel import Babel, gettext as _, lazy_gettext as _l

# In templates
<h1>{{ _('Welcome to the application') }}</h1>
<p>{{ _('Please select your department.') }}</p>

# Date formatting — automatically uses locale
from flask_babel import format_date
format_date(date, format='long')
```

### Implementation Pattern (JavaScript/Node)
```javascript
const i18next = require('i18next');

// In templates/views
i18next.t('welcome.title')  // "Welcome" / "Bienvenue"
```

### Common Pitfalls
- **Don't machine-translate and ship.** Get proper French review.
- **Don't hardcode strings.** Use i18n from day one.
- **Don't forget generated content.** PDFs, emails, and notifications need both languages.
- **Don't forget error states.** Validation messages, 404 pages, etc.
- **Don't forget date/number formatting.** These differ between English and French.

## 4. Federal Identity Program (FIP)

**Source:** [FIP Manual](https://www.canada.ca/en/treasury-board-secretariat/services/government-communications/federal-identity-program.html)

### Web Application Requirements
- [ ] Government of Canada signature (flag + "Government of Canada / Gouvernement du Canada")
- [ ] Canada wordmark in footer
- [ ] Official colours (flag red: #eb1c24; see FIP manual for full palette)
- [ ] Noto Sans font (GCWeb default)
- [ ] No departmental logos competing with GC signature on public-facing pages

### When FIP Applies
- **Public-facing:** Full FIP compliance
- **Internal:** Lighter requirements, GC identification recommended
- **Open source on GC Code:** GC copyright notice required

---

## 5. Web Interoperability Standards

- [ ] HTML5
- [ ] UTF-8 character encoding
- [ ] Machine-readable data formats (JSON, XML) where applicable
- [ ] Responsive design (mobile-first)
- [ ] Support common browsers: Chrome, Firefox, Edge, Safari (latest two versions minimum)

---

## 6. Mobile Standards

- [ ] Responsive design (not a separate mobile site)
- [ ] Touch-friendly targets (minimum 44×44px)
- [ ] Performance optimization for mobile networks
- [ ] No horizontal scrolling at mobile viewport widths
- [ ] Test on iOS Safari and Android Chrome

---

## 7. Privacy

- [ ] Privacy Impact Assessment (PIA) completed if handling personal information
- [ ] Privacy notice displayed explaining data collection and purpose (bilingual)
- [ ] Data minimization — collect only what's necessary
- [ ] Cookie notice if using non-essential cookies
